04

SSH2VPN

Problem
A personal VPN usually means installing a daemon and trusting a provider. An SSH server you already own should be enough.
Approach
NEPacketTunnel data plane relaying over SSH direct-tcpip — stock sshd + AllowTcpForwarding is the only server requirement. iOS + Android + macOS on one core.
Result
On the App Store; the release gate proves the debug channel is in no shipped binary.
  • 589test methods in 66 Swift files + 28 Python gateway tests
  • 3platforms: iOS · Android · macOS on one shared core
  • 17locales · StoreKit paywall · live on the App Store
